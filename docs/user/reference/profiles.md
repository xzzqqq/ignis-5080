Profiles set hardware-specific defaults. Flags, environment variables and config-file values override them. `--profile` defaults to `auto`; `auto` selects a profile by total GPU memory. `--profile none` disables this layer. Define or override profiles in the config file's `profiles:` section. See the [service guide](../README.md#configuration) for the 5080 settings.
